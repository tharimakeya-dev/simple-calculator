# 🎨 CSS Flexbox vs CSS Grid

Knowing when to use Flexbox and when to use Grid is one of the most frequently asked questions in modern web design.

---

## 📌 Key difference:

* **Flexbox (1D - one-dimensional)**: Arranges elements along a single axis only — either as a row or as a column.
  * *Best for*: Navbar menus, button groups, elements inside a card.
* **Grid (2D - two-dimensional)**: Arranges elements into cells across both rows and columns at the same time.
  * *Best for*: Full page layouts (Dashboard layout), galleries, complex card collections.

# 🚀 Core Web Vitals: A Guide to Improving Site Speed

The 3 key metrics defined by Google for evaluating a website's user experience (UX):

---

1. **LCP (Largest Contentful Paint)**:
   * How quickly the main large piece of content (for example, a hero image or a large block of text) becomes visible.
   * *Good score*: < 2.5 seconds.
2. **INP (Interaction to Next Paint)**:
   * How quickly the screen responds when the user clicks a button on the page.
   * *Good score*: < 200 ms.
3. **CLS (Cumulative Layout Shift)**:
   * Elements unexpectedly jumping and changing position while the page is loading.
   * *Good score*: < 0.1.
